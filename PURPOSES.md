# Global purposes written by people

One line a global: `gName - what it is for`. `tools/globals_census.py` reads this file and uses
these words over the comment found beside the declaration.

<!-- Added 2026-11-15 by Claude (Fable 5.2) from the lines that write each global. Stack named in brackets. -->
gErrorIndent - indent text for the debug/error log; handlers reset it to "" and add spaces as calls nest [GAD_WORKING]
gBinaryString - the glyph being edited as rows of 0/1 text (starts as an empty 16 x 16 matrix), read back with getBinaryString() [BitFontMaker]
gCurrentFont - name of the font being edited; set when a font is picked, made or renamed; shown in the FontViewer title [BitFontMaker]
gCurrentAsciiVal - ASCII number of the glyph being edited (0 at start; set by loops and by picking a character) [BitFontMaker]
gCurrentCharacterImage - index of the current glyph's image, gCurrentAsciiVal + 1, or the ImageIndex of the clicked image [BitFontMaker]
gWorldA - the whole current world as an array (name, locations, each type's records); loaded from and saved to stack properties [TTRPG Studio]
gWorldName - name of the current world; set from current.world() or the pWorldName parameter [TTRPG Studio]
gLocationsA - the locations part of gWorldA (gWorldA["locations"]) [TTRPG Studio]
gSourceDirectoryRoot - the chosen source folder; also stored in the stack's Source_Directory_Root property and used as the defaultFolder [Generica]
gSourceDirectoryFolders - the folders found in the source folder (`the folders`) [Generica]
gSourceDirectoryFilesList - the list of loaded files, taken from the card's customKeys [Generica]
gSelectedSourceDirectoryFile - the file (property name) picked from gSourceDirectoryFilesList; line 1 by default [Generica]
gSelectedFileArray - the picked file's content as an array, read from and written to the card property named by gSelectedSourceDirectoryFile [Generica]
gSelectedFileArrayKeys - the keys of gSelectedFileArray [Generica]
gSelectedFileArrayContentList - the values of gSelectedFileArray as lines, one per key [Generica]
gSelectedFileArrayContentSelection - the line picked (or edited) in gSelectedFileArrayContentList; written back into gSelectedFileArray [Generica]
gFirstLevelFolder - the folder picked inside the source folder [Generica]
gFirstLevelFolderPath - gSourceDirectoryRoot & "/" & gFirstLevelFolder; used as the defaultFolder [Generica]
gFirstLevelFile - the file picked in that folder [Generica]
gFirstLevelFilePath - "file:" URL of gFirstLevelFile inside gFirstLevelFolderPath [Generica]
gFirstLevelText - the text of that file (put URL gFirstLevelFilePath) [Generica]
gFirstLevelArrayName - gFirstLevelFile without its 4-character extension; the name its array is stored under [Generica]
gFirstLevelSubArrayLabel - array of that file's label lines under padded numbers ("001"...), plus "description" [Generica]
gCurrentFileList - the files of the current folder (`the files`), or the labels file list [Generica]
gCurrentFilePath - "file:" URL of the file being read or written (folder / key / name.txt, or key_description.txt) [Generica]
gCurrentPropertySet - the custom property set in use on the card (read from and set as the customPropertySet) [Generica]
gLabelsDescription - copy of gCurrentFileList kept for the labels' descriptions [Generica]
gStackFullPath - full file path of the main stack, cut from its long name [Generica]
gStackDirectory - the folder the stack file is in (the path without its last item); used as the default folder [many stacks]
gGlobalPrefixChar - the prefix letter that marks a global name when scanning scripts for globals [Generica]
gGlobalPrefixIgnoreList - prefixes to skip in that scan, from the card's global_prefix_ignore_list property [Generica]
gFoundGlobals - global names found by that scan, one per line [Generica]
gGlobalInitCatch - one generated line `put "name" into name` for a found global [Generica]
gGlobalInitBuild - the generated text of an `on initNewGlobals` handler, built from the found globals (the stack writes its own init script) [Generica]
gButtonPropertyBoolItems - the list of true/false button property names (visible, opaque, showName, autoHilite...) [Generica]
gWidth - width of the working area: gRight - gLeft, or a fixed 512 [Generica]
gHeight - height of the working area: gTop - gBottom [Generica]
gCurrentFrame - number of the BVH frame being shown; stepped by a delta and wrapped to 1 after the last frame [Stick_Figure_Bubble_Man]
gMobilePathIndexLabel - label of a mobile object's path: gMobileIndexLabel with its first letter changed to "p" [GAD_WORKING]
gCameraYaw - camera turn left/right in radians; the mouse adds dx * kMouseSens [Vibecode3D]
gCameraPitch - camera tilt up/down in radians, kept between -1.35 and 1.35; the mouse changes it by dy * kMouseSens [Vibecode3D]
gViewLeft - left edge of the 3D view in the window (0) [Vibecode3D]
gViewTop - top edge of the 3D view in the window (0) [Vibecode3D]
gViewBottom - bottom edge of the 3D view: the stack's height (446 by default) [Vibecode3D]
